## Section 1 — Chats

### The Inbox (Left Panel)
Lists all conversations sorted by most recent activity.

**Filter tabs:**
- **All** — every conversation
- **AI** — only conversations with AI enabled
- **Pinned** — conversations you've pinned to the top

**Conversation actions** (hover or right-click):
- **Pin** — keep at top of list
- **Archive** — hide from main view
- **Reset AI Memory** — delete only AI auto-replies in this chat
- **Clear Chat** — delete all messages locally (does NOT affect customer's phone)

**Search:** Type in the search bar to find conversations by name, phone, or message content. Real-time fuzzy match.

**Collapse:** Press `Ctrl+B` or click the **<** arrow to collapse the inbox into a slim icon strip (more space for chat).

### The Chat View (Middle Panel)
Standard messenger interface with WhatsApp-like styling.

**Sending messages:**
- Type in the input box, press **Enter** to send.
- **Shift+Enter** for new line.
- **📎 (Paperclip)** — attach image, video, document (max 20 MB).
- **😀 (Emoji)** — emoji picker with categories.
- **⚡ (Templates)** — insert pre-built template messages.

**AI controls (top right):**
- **Enable AI / AI Active** button — toggle AI auto-reply for this specific conversation.
- When AI is active, a blue banner shows: *"AI auto-reply is active — incoming messages will be answered automatically"*

**Message indicators:**
- **🤖 Auto-reply** label — message was generated by AI
- **Clock icon** — sending
- **Single check** — sent
- **Double check (gray)** — delivered
- **Double check (blue)** — read

### The Right Panel
Three tabs:

#### Contact tab
- **Avatar + name + phone**
- **Stats:** messages sent / received / AI-generated
- **Display Name** — override the WhatsApp pushname
- **Label** — assign sales pipeline stage (New Lead, Customer, VIP, Support, Closed)
- **Tags** — free-form keywords for filtering
- **Notes** — private notes about this contact

#### AI tab
- **Auto-Reply toggle** — same as the chat header button
- **Detected AI backends** — list of running AI servers
- **Model selector** — choose specific model
- **Test Connection** — verify AI can respond
- **Reply Delay slider** — 0.5 to 10 seconds
- **Custom Persona** — override the default persona for THIS conversation only (great for VIP customers)

#### Knowledge tab
- View, search, edit, delete KB entries
- Toggle entries active/inactive per session

## Section 2 — Quick Send (Hantar Pantas)

Send messages without saving the recipient as a contact.

### Single Mode
1. Select country code (default 🇲🇾 +60).
2. Enter phone number (any format: `01XXXXXXXX`, `123456789`, `+601XXXXXXXX`).
3. Type message (optional if attaching file).
4. Click **Send Now**.

### Bulk Mode (1000+ recipients)
1. Switch to **Bulk** tab.
2. Paste many numbers separated by:
   - New lines
   - Commas
   - Semicolons
3. Set delay between messages:
   - **0ms** — fastest, highest ban risk
   - **300ms** — safe for <50 messages
   - **1.5s** — anti-spam, recommended for 100+
4. Type your message (with attachments optional).
5. Click **Send to N Recipients**.

**⚠ Ban Risk Warning:** WhatsApp may block your account for sending too many messages too fast. For >50 messages, always use 300ms+ delay.

### History
Right sidebar shows last 30 sends with status (✓ ok / ✗ failed).

## Section 4 — Pipeline (Sales Kanban)

Drag-and-drop customer cards across 5 stages:
1. **New Lead** 🆕 — first contact, needs follow-up
2. **In Support** 🛠️ — actively being served
3. **Customer** ✅ — confirmed sale
4. **VIP** ⭐ — top-tier, special treatment
5. **Closed** 💤 — inactive, can re-engage

Each card shows name, phone, recent message preview. Click to open chat.

## Section 5 — Broadcast

Send messages to many contacts at once with personalization.

1. Click **+ New Broadcast**.
2. **Title** — e.g. "Promo Raya 2026"
3. **Message** — supports variables: `{nama}`, `{telefon}`, `{tarikh}`
4. **Recipients:**
   - Select contacts manually, OR
   - Filter by label (e.g. "All VIP")
5. **Send** — confirmation with recipient count.

**Track:** Sent count, fail count, status shown on each broadcast card.

## Section 6 — Templates

Pre-built reply messages organized by category.

### Built-in Categories
- Salam (greetings)
- Maklumat Produk (product info)
- Harga (pricing)
- Bayaran (payment)
- Follow Up
- Penghantaran (delivery)
- Promosi (promotion)
- Terima Kasih (thank you)

### Variables
- `{nama}` — replaced with contact's name
- `{telefon}` — contact's phone
- `{tarikh}` — today's date

### Using Templates Mid-Chat
1. In any chat, click the **⚡ Templates** icon in the input bar.
2. Search or browse.
3. Click a template → text inserted into input → edit if needed → Send.

## Section 7 — Orders

Track customer orders and revenue.

1. **+ New Order**:
   - Select contact
   - Title (e.g. "5 units · iPhone Casing Pro")
   - Amount (RM)
   - Status: new / processing / shipped / completed / cancelled
   - Paid? (toggle)
   - Notes
2. Filter by status.
3. **Revenue summary** at top: total received vs pending.

Link each order to the source conversation for context.

## Section 10 — Reports (PDF)

Generate branded PDF reports for documentation or client reporting.

### Setup Company Profile
1. **Settings → Reports** (or open Reports section directly)
2. Fill in:
   - Company Name (e.g. Maju Electrical Sdn Bhd)
   - Address
   - Phone, Email
   - Upload Logo (PNG/JPG, max 2 MB)
3. Click **💾 Save** to store this profile.

You can save MULTIPLE company profiles and switch between them — useful for agencies serving multiple clients.

### Generate Report
1. Select date range:
   - Quick presets: Today / Yesterday / 7d / 30d / 90d
   - Custom range
2. Live preview updates instantly.
3. Click **Generate PDF Report**.
4. Choose save location.
5. Open generated PDF — includes:
   - Cover page with logo
   - Executive summary
   - Daily trend chart
   - Top 5 customers
   - Full statistics breakdown

## Best Practices

### For AI Quality
- Write a DETAILED business profile (200-500 words)
- Add 50+ KB entries covering products, prices, FAQs
- Use formal "Encik/Cik" addressing in persona
- Set reply delay to 2-4 seconds (mimics human typing)
- Review AI replies for the first week, adjust KB based on mistakes

### For Anti-Ban
- Don't send identical messages to >50 contacts at once
- Vary message templates slightly
- Use 1.5s+ delay for bulk sends
- Don't send from new numbers immediately at high volume
- Reply to incoming messages with reasonable speed (not microseconds)

### For Data Safety
- Enable daily Drive Backup
- Don't share your `%APPDATA%\syncera\` folder with others
- Periodically export reports for offline records
- Test restore on a secondary machine quarterly

## Tips & Tricks

- **Quick context switch:** Use the section icons in the left nav to jump between Dashboard, Chats, Pipeline without losing your place.
- **AI for VIPs:** Disable global AI auto-reply, but enable it per-conversation only for high-engagement customers.
- **Template variables:** Always include `{nama}` for personalization — feels less robotic.
- **Pipeline cleanup:** Weekly, drag inactive Customers → Closed to keep the New Leads column focused.
- **Knowledge Base structure:** Use clear titles ("Pricing: 13A socket") — the AI matches titles 3× stronger than content.
- **Multi-company reports:** If you serve clients as an agency, switch company profiles in Reports to brand each report differently.
