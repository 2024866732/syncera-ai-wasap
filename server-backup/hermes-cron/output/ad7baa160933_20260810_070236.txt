## 📌 Apa Kito Patut Tahu

1. **Safety = competitive feature** — OpenAI slow Astra, Black Hat agent-escape stories, Claude auto-mode classifier. HAFJET agent/WhatsApp/bot stack: audit containment, tool permission, sandbox dulu sebelum auto-mode agresif.

2. **Chip race jadi physical infra** — Terafab $16.8B + Unitree IPO = AI dah tak digital je; robot + fab + energy. Cost-conscious play: optimise inference (AirLLM-style) & local/edge sebelum kejar frontier API mahal.

3. **Open-source “real work” tools** — WeatherNext, Alpamayo, GenOffice, agent-memory. Bukan demo je — weights + commercial license. Worth track untuk OCR/P&L, dashboard, voice, CCTV offload.

4. **Agent skills + memory standard** — Google skills, Tencent memory, book-to-skill, Hermes-style skill packs. Arah industri: durable skills + governed memory, bukan prompt sekali jalan.

5. **Coding agent default lebih autonomous** — Claude Code auto 14 Ogos + Prime/DeepSeek-Reasonix trending. Opportunity: autopilot internal (SPX, pickup, ops) dengan approval gate kekal (audit-first HAFJET style).

6. **Free tier pressure** — Unlimited ChatGPT text + open office suite. Product strategy: value di data HAFJET, workflow, integration (WA/Loyverse/Supabase), bukan raw chat saja.
