## 📌 Apa Kito Patut Tahu

1. **AI dah jadi regulated industry.** Model besar macam GPT-5.6 kena approval gov dulu sebelum release. Kalau Tuan ada projek guna API model besar, kena ambil tahu compliance ni.

2. **Open-source AI menang — dari segi pilihan, kos, dan control.** DeepSeek V4-Flash #1, MiniMax M3 lawan GPT-5.5, ZAYA1-8B trained on AMD. Vendor lock-in dah kurang relevan.

3. **Duit besar masuk infrastructure AI, bukan model je.** SambaNova ($1B), Blue Origin ($10B), Meta Canada ($13B), DigitalOcean (9-figure deals). Inference, chip, data centre — ni tempat pelaburan sebenar.

4. **Geopolitik AI memanas.** US nak restrict model China, China pulak nak restrict model diorang. Developer kena prepare untuk fragmented AI ecosystem.

5. **Kalau nak mula guna open-source AI skarang:**
   - Jangan ikut leaderboard semata-mata — workflow lebih penting
   - DeepSeek V4-Flash atau MiniMax M3 pilihan terbaik untuk coding
   - OpenClaw untuk messaging gateway (Telegram, WhatsApp, Discord)
   - smolagents untuk lightweight agent prototyping

6. **Server kita 1GB RAM + 4GB Swap — sesuai untuk Hermes Agent atau smolagents.** Model besar kena guna API jelah.
