- **🌍 Terra** — tengah-tengah
- **☀️ Sol** — paling gempak
Sebelum ni model ni dikurung 13 hari untuk ~20 organisasi yang diluluskan kerajaan US. Fasa "government preview" ni first of its kind — tanda kerajaan US makin campur tangan dalam frontier AI releases.

Seorang investor cakap: *"Open-source models eventually akan handle 95% of enterprise queries, and that remaining 5% may go to OpenAI or Anthropic."*

**🦜 Colibri — LLM 744B Parameter Jalan Atas PC Biasa!**
Ni yang paling **goni** untuk kita di HAFJET — **Colibri**, engine inference tulen C (~2400 lines, zero dependencies) yang boleh run **GLM-5.2** (744 billion parameters, Mixture-of-Experts model dari Zhipu AI) atas consumer PC dengan **hanya ~25GB RAM**. CARANYA: stream experts dari disk, bukan muat semua dalam memori. No GPU required. Kalau server kita ada storage 512GB plus swap 4GB... maybe boleh cubat? 🤔

**🏗️ OpenAI Agent SDK — Sekarang Dah Open Source!**
OpenAI buka dua repo baru: **openai/openai-agents-js** dan **openai/openai-agents-python**. Framework ringan untuk bina multi-agent workflow. Provider-agnostic — support OpenAI dan 100+ LLM lain. Ada handoffs, guardrails, structured outputs. Replacement untuk eksperimen Swarm dulu.
