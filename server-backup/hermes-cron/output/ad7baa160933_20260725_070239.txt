## ⭐ Projek GitHub Naik Bukit (July 2026 Trending)

Data dari Analytics Vidhya, BytePointer & ossinsight — trend bulan ni: **bukan lagi model, tapi agent tooling** yang naik:

- **Coding agent harnesses** (macam Grok Build, Kilo, Claude Code) — repo untuk autonomous code generation makin naik
- **MCP servers** (Model Context Protocol) — official GitHub MCP server & ekosistem MCP.so / mcpmarket sedang naik
- **Pentesting & trading agents** — autonomous security + financial agent repos makin aktif
- **AI gateways & infra** — LiteLLM, proxy tools untuk routing & cost management
- **Voice tools & local inference** — local-first AI, bukan cloud-dependent

Ramai penganalisis cakap: frontier-model race dah sebahagiannya give way kepada **infrastructure race**. Bila dah ada beberapa base models kuat, bottleneck sekarang ialah buat agents yang reliable, efficient, dan safe.

## ⚠️ Security Alert: FakeGit Campaign (Penting!)

- **7,600 malicious GitHub repositories** ditanam untuk spread SmartLoader malware
- 800+ repos pretending jadi "AI skills" atau "MCP servers"
- Teknik baru dipanggil **"agentbaiting"** — tricks AI agents (macam Claude Code, Cursor) untuk recommend repo malicious ni kat users
- Lebih 14 million downloads logged sejak March
- **Untuk HAFJET:** Pastikan verify each MCP server atau AI skill sebelum install. Jangan trust repo semata-mata sebab AI agent cadang. Check star/fork ratio, maintainer credibility, dan guna sandbox untuk execution.

  Sumber: [The Hacker News](https://thehackernews.com/2026/07/fakegit-campaign-uses-7600-github.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/fakegit-campaign-uses-7-600-github-repos-to-push-smartloader-malware/)

## 📌 Apa Kito Patut Tahu (Key Takeaways)

1. **AI performance dah sapu competitive math** — Huawei/Xiaohongshu IMO 100% bermakna frontier reasoning dah dekat perfect untuk bounded problems. Expect dorang akan masuk code generation & logical reasoning domains pula.

2. **Open-source AI jadi mainstream strategy** — Dari Grok Build (xAI) ke Mistral ke China labs, open-weight dah jadi taktik geopolitik & enterprise. Bagus untuk kito — more choices, lower cost, no vendor lock-in.

3. **MCP ecosystem booming** — Trending GitHub dah pindah dari "model papers" ke "agent infrastructure." MCP servers, coding harnesses, dan AI gateways adalah yang Agile. HAFJET punya LiteLLM + OpenCode setup betul-betul on-trend.

4. **Agent supply-chain security urgent** — FakeGit "agentbaiting" is a new attack vector. Bila AI agents decide repo mana nak guna, dorang boleh kena manipulated. Wajib ada vetting workflow (skill `hf-model-vetting` kito patut extend ke MCP/skill vetting).

5. **Small models (3B) boleh lawan flagship** — VibeThinker-3B proves compact + clever post-training > raw scale. Relevan untuk HAFJET punya low-RAM server setup — models kecil tapi powerful, boleh run local.
