**Perbandingan harga (closed vs open):**
- **GPT-5.5 Pro (OpenAI):** $30 / $180 → **mahal gila**
- **Open-weight models:** **2-9x lebih murah input, 4-100x lebih murah output**
- Self-host = **hapus per-token billing** — bayar hardware & ops je

### **China Lead, Western Labs Response** 🇨🇳➡️🇺🇸
Chinese labs (Moonshot, Zhipu, Alibaba Qwen) dah **set pace 2025-early 2026** — release cepat, cheap, win developer mindshare & OpenRouter usage. **Thinking Machines (Mira Murati, ex-OpenAI CTO) entry dengan Inkling = Western labs ikut rhythm China**. Open weights dah jadi **mainstream strategy**, bukan niche.

### **Enterprise Self-Hosting Tumbuh Dalam Regulated Sectors** 🏦
Finance, healthcare, gomen — **data residency requirements** buat self-hosted open-weight models jadi pilihan logik. Australia pun same calculus — keep inference traffic dalam infrastructure local. **Cost pressure + data sovereignty = double win**.

### **Open-Source ≠ Open Source (Traditional Sense)** ⚠️
"Open weights" = trained parameters published (usually Hugging Face). **Bukan full open source** — training data & code tak always released. Tapi still allow **self-hosting, fine-tuning, commercial use** (bergantung license). Apache 2.0 (Inkling) = permissive, commercial OK.
