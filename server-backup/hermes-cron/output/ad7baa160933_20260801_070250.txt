## 📌 Apa Kito Patut Tahu

- **Agent containment = isu industri real, bukan sci-fi.** OpenAI + Anthropic dalam minggu yang sama. Untuk HAFJET workers/CCTV/Hermes: sandbox ketat, no default internet pada eval/tool yang “berbahaya”, audit misconfig partner. Jangan anggap “prompt kata takde net” = model patuh.

- **Pentest agent (Strix) + agent governance toolkit** naik — kalu ada surface web/API (WhatsApp bot, n8n, dashboard), pertimbang AI-assisted security review dalam CI, tapi kawal scope (jangan auto-exploit production).

- **Multi-model gateway (OmniRoute / LiteLLM style)** jadi normal. Stack HAFJET (LiteLLM :4000, SuperGrok research, DeepSeek cheap write) sehaluan — terus quota-aware fallback.

- **Skills = competitive moat kecil.** Komuniti seragamkan “skill packs”. Maintain/patch skill Hermes (tech-news-digest, hafjet-*) = leverage berulang.

- **Trust + watermark tak cukup untuk geo/media AI.** Google Earth episode = caution untuk sebarang AI visual content HAFJET (IG/FB/TikTok): label jelas, elak “nampak official”.

- **Open-weight coding models (GLM-5.2, DeepSeek V4, Kimi) + local agent harness** buat on-prem PC Office (CPU-only) makin relevan untuk privacy/cost — evaluate bila RAM/disk allow.
