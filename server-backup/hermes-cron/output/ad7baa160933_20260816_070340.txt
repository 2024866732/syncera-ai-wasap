## 🤖 Dunia Open-Source AI Minggu Ni

- **Frontier AI “pecah 3 pasaran”** (AI Weekly #521, 12 Ogos) — Bukan lagi satu leaderboard. Tiga leverage: (1) kawal *access* ke intelligence, (2) *own* the model (open weights), (3) jadi *router/intermediary* yang pilih model mana untuk job mana. Gateway/routing = strategic layer.

- **Open-weight stack Ogos 2026 (landscape)** — DeepSeek **V4** (coding/agentic, context 1M, MoE), **GLM-5.2** (long-horizon software), **Kimi K3** (2.8T, vision + long context), **Qwen3.6-35B-A3B** (efficient multimodal MoE, 3B activated), **gpt-oss** 20B/120B (boleh local). Mid-size 7–13B still workhorse untuk consumer/local.

- **Label “open source” vs “open weights”** makin serius — majority release = weights open, data tutup. Regulasi (EU AI Act, US reporting) tekan open weights di atas threshold capability. Enterprise pilih open weights sebab **data privacy + cost**, bukan sebab “fully open”.

- **Cloudflare `@cloudflare/computer`** — “Agent needs a computer, not a container.” Runtime workspace (Durable Object + sandbox + browser) untuk agent coding/ops. Repo `cloudflare/computer` naik trending. Relevant sangat untuk stack HAFJET yang dah main Cloudflare.

- **Agent Skills ecosystem sohor** — `addyosmani/agent-skills`, `google/skills`, diagram-design skills untuk Claude Code. Trend: packaging SOP/workflow sebagai SKILL.md supaya coding agent consistent.

- **NVIDIA NeMo Switchyard** — LLM traffic router, OpenAI/Anthropic API compatible, multi-provider failover + cost/perf optimization. Tema yang sama dengan gateway/proxy pattern.

- **Tiny on-device model** — `cactus-compute/needle` (~14MB foundation model) untuk phone/wearable/smart home/robot. Edge AI terus pacak megah.

## 📌 Apa Kito Patut Tahu

1. **Security dulu, goni** — Patch Windows ASAP; pastikan tiada Screen Sharing/VNC expose ke internet (Mac/PC). Apple spyware alert = treat seriously + Lockdown Mode kalau relevan.

2. **Agent containment = due diligence** — Kongres dah tanya OpenAI/Anthropic pasal agent lepas sandbox. Kalau HAFJET deploy agentic tools (Hermes, WhatsApp bot, n8n, CCTV workers), pastikan network boundary, least privilege, audit log.

3. **Watermark AI content** — Anthropic dah start; EU tekan transparency. Content automation HAFJET (n8n + social drafts) patut assume detection akan jadi normal — human edit + brand voice tetap kritikal (HITL dah betul).

4. **Router/gateway layer menang jangka panjang** — Switchyard, LiteLLM, OmniRoute pattern: multi-model failover + cost control. Sejajar arah HAFJET (DeepSeek text, SuperGrok image/video, local Ollama).

5. **Skills > one-off prompts** — GitHub trending confirms: reusable SKILL.md / agent-skills = leverage. Continuously maintain Hermes skills (kito dah buat ni — terus bersenggoti).

6. **Local/open-weight masih relevant** — Mid-size + tiny models + code-graph RAG bagus untuk on-prem (PC Office, Oracle bot, privacy). Edge/tiny model (`needle`) worth pantau untuk device/IoT later.

7. **Leadership & platform shift** — Apple CEO handover Sept 1; Google Pixel+Gemini hardware push; frontier lab strategy split. Budget-conscious stack (open weights + selective frontier API) still smart play.
