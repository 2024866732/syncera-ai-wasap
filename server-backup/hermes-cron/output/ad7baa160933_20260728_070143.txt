## 🤖 Dunia Open-Source AI Minggu Ni

- **Open-weight ada nilai operasi sebenar, bukan sekadar idealisme.** Dalam pendedahan Hugging Face, pasukan forensik menggunakan **GLM 5.2** secara lokal apabila API model komersial menyekat analisis artefak serangan. Data sensitif dan credential pun tak perlu keluar dari infra sendiri.

- **Pengajaran security yang besar:** Hugging Face menyatakan akses awal datang daripada laluan pemprosesan dataset—remote-code loader dan template injection. Mereka sudah menutup laluan tersebut, membina semula node terjejas, serta memutar semula secrets/token.

- **Agen AI ofensif sudah praktikal.** Hugging Face melaporkan kempen itu menggunakan ribuan tindakan automatik dalam sandbox jangka pendek. Maksudnya, threat model untuk servis AI, worker dan pipeline data kena lebih ketat, doh.

- **Debat open-source makin strategik.** Bukan sekadar “open lawan closed”: model lokal/open-weight memberi pilihan untuk privasi, audit dan kerja security yang mungkin tersekat oleh polisi API hosted.

## 📌 Apa Kito Patut Tahu

- **Sedia model lokal untuk kerja sensitif.** Simpan pilihan model open-weight yang telah diuji untuk analisis log, OCR/dokumen, dan kes security—jangan bergantung penuh pada API luar.
- **Kunci pipeline data AI.** Dataset, upload fail, worker dan template merupakan attack surface; elakkan execution lalai, asingkan worker, scan input, dan rotate secrets secara berkala.
- **Bina AI stack berlapis.** Guna routing antara hosted model, local model, dan fallback provider supaya bot/automasi HAFJET tidak tersangkut jika satu provider mahal, down, atau block tugasan.
- **Pantau tools agent, bukan model saja.** Projek seperti `ai-agent-book`, `awesome-claude-skills`, dan `kimi-cli` menunjukkan ekosistem sekarang bergerak kepada tool-use, CLI dan orchestration.
- **Cybersecurity automation patut masuk roadmap.** Kena ada alert triage dan ringkasan log berasaskan AI, tapi dengan approval boundary yang jelas—jangan bagi agen akses produksi tanpa guardrail.
