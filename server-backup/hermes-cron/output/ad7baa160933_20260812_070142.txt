## 📌 Apa Kito Patut Tahu

1. **Money follow compute** — Nvidia tak jual chip je; dia bantu Wall Street jadikan GPU/data center *financeable infrastructure*. Capex AI (CoreWeave dsb.) masih naik, backlog gila.  
2. **Open weights vs closed** — Nvidia (Nemotron 4), Meta (Muse Glimmer) push open/local agent; closed labs still raise gila (River, OpenAI tender). Hybrid world.  
3. **Agent era, bukan chat era** — GitHub, Grok Bot, Nemotron Lightning, River “trainable personal agents” — semua point ke always-on, tool-use, multi-step.  
4. **Linux + local stack** — ChatGPT Linux app + open models yang fit single GPU = opportunity untuk setup macam HAFJET (self-host, cost control).  
5. **Safety/transparency naik** — watermark, AI labels, open-model cyber risk discussion selepas agent hacks. Audit-first tetap betul.  
6. **Valuation frothy** — 2-month-old @ USD 1.1B seed = market masih spekulatif. Pilih tools yang solve real ops, jangan FOMO je.

**Angle HAFJET (practical):**  
- Pantau **Nemotron / Muse Glimmer / Ollama-compatible** untuk agent local (WhatsApp bot, OCR, SPX reminder stack).  
- **Model routing** (gaya NeMo Switchyard) = potong cost API.  
- Skills repos (agent-skills, Anthropic skills, agency-agents pattern) boleh inspirasi Hermes skill packs.  
- Budget-conscious: neocloud pricing naik; prefer open + own hardware where sensible.
