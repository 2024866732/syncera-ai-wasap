## 🔥 Berita Teknologi Paling Panas

- **Google jadikan Search + Gemini lebih “study-first”.**  
  Google melancar visual interaktif, simulasi 3D, kuiz tersuai, bahan ulang kaji daripada fail pengguna, serta *Deep Research* dalam Gemini Live. Bagi pelajar dan pembelajaran dalaman staf, ni boleh jadi pesaing terus kepada workflow NotebookLM/ChatGPT. [1]

- **Claude mula watermark teks AI secara lebih serius.**  
  Anthropic menerangkan watermark tak nampak pada teks Claude: tiada aksara tersembunyi, tiada token/caj tambahan, dan direka supaya kualiti tulisan kekal sama. Ia berkait pematuhan EU AI Act. Untuk content automation HAFJET, simpan jejak asal, semakan manusia dan disclosure—jangan bersenggoti harap output AI bulat-bulat. [2]

- **Stripe–OpenRouter: laporan urus niaga besar, tapi belum rasmi.**  
  Laporan media menyebut Stripe dikatakan setuju mengambil alih OpenRouter pada nilai melebihi **US$7 bilion**. Kedua-dua pihak belum mengesahkan secara terbuka, jadi anggap sebagai *reported deal*, bukan fakta muktamad. Jika jadi, model-routing API pacak megah sebagai lapisan infrastruktur AI utama. [3]

## 🤖 Dunia Open-Source AI Minggu Ni

- **OpenViking sedang sohor untuk “agent memory”.**  
  Projek ini susun memori, sumber RAG dan skills sebagai virtual filesystem `viking://`; konteks dimuat ikut lapisan ringkas → terperinci. Menarik untuk agent jangka panjang sebab retrieval boleh diperhati/debug, bukan kotak hitam vector search semata-mata. [4]

- **Unsloth makin kemas sebagai pintu masuk AI lokal.**  
  Ia sediakan desktop/UI untuk run, fine-tune dan deploy LLM/diffusion secara lokal, dengan sokongan CPU, NVIDIA, AMD, Intel dan Apple Silicon; juga OpenAI-compatible API. Sesuai diuji di node GPU HAFJET—bukan pada VPS 1GB RAM. [5]

- **GLM-5.3 muncul untuk reasoning, coding dan agent jangka panjang.**  
  Model Z.ai ini dilancarkan 18 Ogos, namun statusnya **bukan open-weight yang bebas dimuat turun pada pelancaran**—weights dilaporkan masih melalui semakan keselamatan. Jadi jangan keliru dengan model benar-benar open-source, goni. [6]

## 📌 Apa Kito Patut Tahu

- **Model routing makin strategik:** kalau berita Stripe–OpenRouter benar, pemilihan model, fallback dan kos inference bukan benda sampingan lagi. HAFJET patut kekalkan abstraction gateway supaya tak terkunci pada satu provider.
- **Open-source bergerak ke arah “agent infrastructure”, bukan model sahaja.** Memory, context engineering dan observability macam OpenViking mungkin lebih memberi kesan kepada agent production berbanding tukar model tiap minggu.
- **HITL masih wajib untuk content.** Watermark Claude dan tekanan regulatori menjadikan provenance, log prompt dan semakan manusia lebih penting untuk workflow n8n/content HAFJET.
- **Lokal GPU ada nilai sebenar.** Unsloth dan projek model ringan tunjuk workflow private/local makin matang—guna node RTX untuk eksperimen; VPS kecil kekal fokus orchestration/API ringan.
- **AI pendidikan sedang jadi medan besar.** Google gabung Search, visual interaktif dan Gemini. Untuk pelajar, ini boleh bantu faham konsep; untuk kerja, jadikan ia pembantu research—bukan sumber akhir tanpa semak.
