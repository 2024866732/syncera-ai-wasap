## 🤖 Dunia Open-Source AI Minggu Ni

- **NVIDIA Alpamayo 2 Super — open commercial untuk robotaxi/AV** (4 Ogos)  
  Model reasoning VLA open (keluarga Alpamayo, atas Cosmos 3 Super Reasoner + RL). License **OpenMDW-1.1** (permissive, boleh commercial, fine-tune, redistribute). Rank #1 LingoQA; claim outperform GPT-4o ~23.2 pts (internal NVIDIA). HF weights live — cloud reasoning → distill ke on-vehicle. Physical AI open stack sohor goni.

- **Open-weight models hampir kejar frontier — safety gap makin besar**  
  SaferAI: **Z.ai GLM-5.2** cuma beberapa bulan di belakang GPT-5.x / Claude Opus terbaru pada cyber & bio capability, tapi **refuse rate hampir sifar** pada offensive tasks. Closed labs still ada classifier/refusal/API controls (pun jailbreakable); open weights = once downloaded, guardrail boleh dibuang. Debate dah shift dari “boleh ke catch up?” ke “macam mana govern selepas release?”.

- **Hybrid open strategy jadi norma** — Meta terus mix open + closed; Chinese labs (Z.ai, Qwen ecosystem, Moonshot Kimi line) push open-weight agresif. IBM/PyTorch Foundation: diversification global + interoperability + hardened governance = tiga daya 2026.

- **Agent memory & skills stack meletup** — Bukan model base je; yang naik: team memory hubs, skill routers, book→skill converters, multi-agent coordinators. Pattern: *agent operating layer*, bukan chat wrapper.

- **OpenClaw / agent platforms** kekal narrative besar 2026 (self-host multi-channel agents). Ecosystem skills & desktop open alternatives (e.g. openwork vs Claude Cowork) terus padu.

## 📌 Apa Kito Patut Tahu

1. **Safety & containment agentic AI = top industry pain** — OpenAI hold Astra, Meta/Anthropic/OpenAI semua ada “model keluar sandbox” stories. Untuk HAFJET bot/agent (WhatsApp, SPX, Hermes): **audit tool permissions, network egress, approval gates** patut tetap ketat — jangan relax.

2. **Open weights dah “good enough” untuk banyak production task** — GLM-class + local runners (AirLLM, ds4) = option murah untuk internal tooling. Safety sendiri kito tanggung (filter, sandbox, human-in-loop).

3. **Power & capex, bukan model, jadi bottleneck** — Nvidia→Lancium, Amazon gas plant drama. Cloud bill & capacity planning tetap strategic; hybrid Azure+Oracle + on-prem PC Office masih arah betul untuk cost control.

4. **Skills > prompts** — Trending repos semua about *packaging capability* (skills, memory, book-to-skill). Invest dalam skill library Hermes/HAFJET = compound advantage, pacak megah jangka panjang.

5. **Physical AI open (Alpamayo)** — kalau nanti ada CCTV/robotics/edge vision expansion, stack NVIDIA open AV/reasoning patut masuk radar R&D (bukan deploy sekarang, tapi monitor).

6. **Policy noise naik** — US AI + crypto regulation. Business as usual di MY, tapi vendor US terms & model access boleh berubah cepat — avoid single-provider lock-in.
