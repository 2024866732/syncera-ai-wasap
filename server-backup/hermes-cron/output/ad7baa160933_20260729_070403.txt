## 🤖 Dunia Open-Source AI Minggu Ni

- **Open Secure AI Alliance** — bukan sekadar kempen polisi; ia mengangkat open tooling sebagai komponen *cyber defence* praktikal. Trend besar: security agent perlu boleh berjalan dalam infra sendiri dan disesuaikan ikut konteks organisasi.

- **Open-weight vs closed API semakin bersenggoti.** Closed model bagus untuk kemudahan dan kawalan vendor; open-weight pula beri kawalan data, fleksibiliti fine-tuning dan operasi offline/self-hosted—penting untuk bisnes yang jaga data pelanggan.

- **AI agent engineering makin matang.** Komuniti GitHub bukan hanya kejar chatbot; projek yang naik termasuk gateway multi-model, context compression, MCP, code intelligence dan toolkit agent.

- **Arah pasaran:** Open source AI sedang beralih daripada “projek eksperimen” kepada lapisan infrastruktur—routing model, observability, deployment, governance dan keselamatan.

## 📌 Apa Kito Patut Tahu

- **Keselamatan agent kena jadi default:** asingkan credential, hadkan egress/network, guna least privilege, logging dan human approval untuk tindakan berisiko. Jangan bagi agent “lepas bebas”.
- **Self-hosted/open-weight ada nilai strategi:** khususnya untuk data sensitif, operasi offline dan kawalan kos; tetapi model provenance, patching dan guardrail mesti dijaga.
- **Multi-model routing makin berbaloi:** gabung model tempatan untuk kerja rutin dengan API frontier untuk tugasan susah boleh turunkan kos dan elak vendor lock-in.
- **MCP, context management dan code graphs** semakin penting daripada sekadar benchmark model—itulah komponen yang buat agent benar-benar berguna dalam workflow.
- **Untuk HAFJET:** OmniRoute dan code-review-graph paling berpotensi untuk dipantau; satu untuk ketahanan/cost routing, satu lagi untuk coding agent yang tak membazir context. Molek kalau kito nilai dalam sandbox dulu, jangan terus masuk production.
