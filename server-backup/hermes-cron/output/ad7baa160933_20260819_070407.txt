## 🤖 Dunia Open-Source AI Minggu Ni

- **Meta “Glimmer” — model open-weight.**  
  TechCrunch melaporkan Meta melepaskan Glimmer untuk dimuat turun dan dijalankan atas hardware sendiri, berbeza dengan model lebih berkuasa yang kekal API-tertutup. Ini pacak megah trend hybrid: model terbuka untuk kawalan/kos, model tertutup untuk capability premium. [2]

- **Needle 2: tool-calling AI sangat kecil untuk edge device.**  
  `cactus-compute/needle` membawa model terbuka 45M parameter dalam binary **14MB**, dengan sesi penuh sekitar **28MB RAM**. Ia fokus tool-calling, device use dan structured extraction—menarik untuk IoT, automasi ringan dan mesin RAM terhad. [3]

- **Prime Agent: agen kod/research yang boleh tahan lama.**  
  `PrimeIntellect-ai/prime-agent` guna pendekatan Recursive Language Model, persistent REPL, sub-agent, memori/harness yang boleh diperhalusi, dan sesi daemon-backed. Cuma kena berjaga-jaga: README sendiri tegas bahawa ia **bukan security sandbox**; jangan bagi akses repo atau server production secara sembrono. [4]

- **Unsloth semakin jadi “local AI workstation”.**  
  Projek ni sekarang bukan semata-mata fine-tuning: ia bawa desktop app untuk run/train LLM, image, video, audio dan model embedding secara lokal; sokong CPU, NVIDIA, AMD, Apple serta OpenAI-compatible API. Ada juga integrasi untuk Hermes Agent, Codex dan Claude Code. [5]

## 📌 Apa Kito Patut Tahu

- **AI gateway makin strategik.** Rumor Stripe–OpenRouter menunjukkan routing antara model, billing, observability dan fallback memang lapisan core. HAFJET patut kekalkan architecture provider-agnostic; jangan bersenggoti pada satu vendor.
- **Local/edge AI makin realistik.** Needle membuktikan tugasan structured/tool-call tertentu tak semestinya perlukan GPU besar atau API cloud—sesuai untuk node ringan, device dan automasi bounded.
- **Agen autonomi perlukan boundary ketat.** Prime Agent menarik untuk kerja berulang yang panjang, tetapi sandbox, least privilege, clean worktree dan approval gate kekal wajib.
- **Developer workflow sedang berubah.** Origin oleh Cursor menunjukkan repo hosting + AI agent + coding environment mula bercantum. GitHub masih dominan, tapi pasaran mula buka ruang alternatif.
- **Untuk HAFJET:** teruskan corak **HITL + audit trail + fallback model**. Itu bukan lambat, Tuan Hafizi—itu cara deploy yang tahan lasak bila skala naik.
