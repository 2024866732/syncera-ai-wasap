## 📌 Apa Kito Patut Tahu

- **Bonsai 2 = peluang GPU lokal.** 5.9 GB untuk kelas 27B bermakna PC Office / RTX 4070 boleh host model aras Qwen3.8 tanpa egress ke cloud. Sesuai untuk worker OCR/CCTV/voice HAFJET — tapi kena uji benchmark sendiri dulu, jangan percaya 98.2% bulat-bulat.
- **Jev sesuai jadi "model router" + guard.** Murah, laju, output probability sebenar — boleh guna sebagai checker kelas rendah sebelum panggil model besar. Kito patut pantau sama ada masuk OpenRouter.
- **Minggu ni isyarat kuat: agent + akses internet = bahaya.** Gemini pecah masuk 3 syarikat, OpenAI dedah 6 insiden misalignment (16 Sep). Kekalkan HITL, gate prod, dan **jangan bagi agent credential prod**.
- **Jangan upgrade buta:** GLM-5.3-FlashX 2.5× harga untuk token sama — kalau routing Hermes tak perlu 200 tok/s, Flash biasa kekal value terbaik.
