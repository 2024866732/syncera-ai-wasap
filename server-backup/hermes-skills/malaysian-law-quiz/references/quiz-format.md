# Quiz Answer Format

## True/False Questions
User provides a statement with two options (O True / O False).
- Answer with the correct option clearly marked
- Follow with a brief explanation citing the relevant section/case
- Keep explanation to 2-3 sentences max

## MCQ Questions
User provides a question with multiple options.
- State the correct answer
- Brief legal justification

## User Preferences
- Tuan Hafizi is a Malaysian law student
- Prefers direct answers first, explanation second
- Uses Bahasa Malaysia for communication
- Wants concise, exam-focused answers
- Gets frustrated with over-explaining or unnecessary detail
