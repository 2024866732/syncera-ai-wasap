# SPX Anti-Bot System Discovery (Jul 2026)

## Summary

`show_secret` endpoint is protected by Shopee's anti-bot system (`@shopee/secure-fetch-utils` v1.12.39). The `x-sap-ri` and `x-sap-sec` headers are per-request tokens generated by client-side JavaScript. They CANNOT be captured and reused.

## Architecture

The SPX portal (sp.spx.shopee.com.my) is a Webpack Module Federation SPA:

- **Framework:** Vue 2.6.14 + Vue Composition API
- **HTTP client:** Axios 0.20.0
- **Anti-bot module:** `@shopee/secure-fetch-utils` v1.12.39 (webpack chunk 3421, ~60KB)
- **Request layer:** `@ssc/request` v0.0.2 (chunk 4119) — custom axios wrapper
- **Shared utils:** `@spx-portal/shared-utils` v0.2.2-beta.3 (chunk 6201)

## Headers Analysis

| Header | Length | Format | Behavior |
|--------|--------|--------|----------|
| `x-sap-ri` | 52-64 chars | Hex (varies between captures) | Per-request nonce/identifier |
| `x-sap-sec` | ~724 chars | Base64-like encrypted payload | Per-request signed data |
| `device-id` | Static | `v2-MmYeRgaFMgI2X-ZbOc_fC` | Hardcoded in SPX portal |
| `app` | Static | `SP Portal` | Hardcoded |

## Testing Results

| Test | Headers | Response |
|------|---------|----------|
| show_secret with captured x-sap-ri/x-sap-sec | Included | HTTP 200, retcode 500 |
| show_secret WITHOUT any SAP headers | None | HTTP 200, retcode 500 |
| show_secret with re-captured fresh values | Included | HTTP 200, retcode 500 |

**Conclusion:** Same `retcode: 500` "The service error" regardless of SAP header presence/absence. SPX server-side validation rejects ALL requests that don't come through the real browser client with valid per-request tokens.

## Endpoint Comparison

| Endpoint | SAP Headers | Status |
|----------|------------|--------|
| `/sp-api/point/order/collection/list` (order list) | NOT required | ✅ Working |
| `/sp-api/order/show_secret` (phone reveal) | REQUIRED (per-request) | ❌ Blocked |

## Decision

show_secret API integration is NOT viable for production. All phone population should use CSV import or bulk phone mapping.
